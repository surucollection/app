# Suru Collection Android App

This is a separate Android application project for Suru Collection.

- The app opens the existing live store at https://suru.com.np/
- No website source files are copied into this repository.
- No Supabase schema, data, or configuration is changed by this app project.
- Payment and checkout flows continue to use the live website.

## Build from an iPhone

1. Open the **Actions** tab in this repository.
2. Select **Build Android APK**.
3. Tap **Run workflow**.
4. After the workflow completes, open the run and download the **suru-collection-debug-apk** artifact.

The debug APK is intended for direct testing on Android devices.
